# wx-publish 主题预览

这是 AG-雷达公众号排版主题的**最小公开预览站**。

- 包含：主题总览页与 10 套固定样张；
- 不包含：公众号草稿、文章素材、发布配置、凭据、内部脚本或源主题组件库；
- 主题组件库与管理工具维护在私有仓库 `ccwq/wx-publish`。

## 本地预览

```bash
python3 -m http.server 4174
```

打开 `http://127.0.0.1:4174/`。
