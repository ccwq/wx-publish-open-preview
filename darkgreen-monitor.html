这是一份「深绿监控风」主题样稿，用于对比视觉语言与内容结构：LED 状态灯、进度条、告警条、命令块与记录卡的全部语义都会依次出现。文中出现的端口、延迟、百分比等数值全部是演示口径，并非任何真实机器的实测结果。

01PART 系统快照SNAPSHOT

监控台的第一屏是服务状态清单。主题把它渲染成单列记录卡：每张卡带状态灯，状态文字与灯色的对应关系是固定的：

· UP → 绿色灯；

· WARN → 琥珀灯；

· DOWN → 红色灯。

02PART 健康阈值THRESHOLD

进度条按百分比自动切换健康色：低于 60 走绿色档，60–84 走琥珀档，85 以上走红色档。数值越高代表压力越大，这与「健康得分」类指标是两种口径。

CPU LOAD（演示值） 34%

 

演示口径：低于 60，走绿色档

MEMORY USAGE（演示值） 72%

 

演示口径：落在 60–84，走琥珀档

QUEUE PRESSURE（演示值） 92%

 

演示口径：达到 85 以上，走红色档

INFO
