01 ECOSYSTEM

三版本速览

0.84.0 · 2026-08-06 Provider API 重构 + 事务性 Context ModelsRequestTransforms 替换 ModelsStreamTransforms，统一请求/响应标准化路径；Fireworks GLM 5.2 缓存修复。context.stored 存储中间状态，context.publish() 提交变更，原子化操作避免状态污染。
0.84.1 · 2026-08-07 Qwen 订阅制 + DeepSeek 兼容修复 新增订阅制模型目录 Provider，支持 Qwen 全系订阅模型，Token Plan 订阅用户可直接接入。大写 Hostname 兼容问题修复，API 端点解析正确，V4/V3 全系兼容。
0.84.2 · 2026-08-14 Kimi UA 修复 + 严格 Tool Schema 兼容 Kimi Coding 请求改用 runtime User-Agent，绕过爬虫检测，提升 Kimi 模型可用性。严格工具 schema 自动转 provider 兼容 closed objects，避免 schema 冲突导致的调用失败。
