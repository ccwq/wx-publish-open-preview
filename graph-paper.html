LLM Agent 技术图谱：推理、记忆与工具三角关系

推理引擎 ↔ 记忆系统 ↔ 工具调用，三者构成现代 LLM Agent 的核心三角。

01
推理引擎

Chain-of-Thought

通过分步推理将复杂问题分解为可验证的子步骤，是 Agent 规划能力的基础。

02
记忆系统

向量检索 + RAG

将外部知识编码为向量，实时检索最相关内容注入上下文，解决模型知识截止问题。

03
工具调用

Function Calling

结构化函数调用协议，将 LLM 输出映射为可执行的工具操作，实现 Agent 与外部世界的交互。

推理引擎 → 记忆系统 提供背景

推理需要记忆提供事实基础，两者通过注意力机制深度耦合。

推理引擎 → 工具调用 执行计划

推理引擎生成的执行计划通过 Function Calling 映射为具体工具调用。

记忆系统 ↔ 工具调用 双向反馈

工具执行结果写入记忆，记忆再指导后续推理与调用策略。

FRAMEWORK

框架对比：三种 Agent 架构的节点关系

基于上述三角关系，主流 Agent 框架可以分为三类： ReAct （推理驱动）、 RAG-First （记忆优先）和 Tool-Forward （工具前置）。每种架构对三角顶点的优先级不同。

DEFINE

Function Calling: { name, arguments } → { tool, result }


  •  ReAct：推理→行动→观察的循环，适合需要多步验证的任务。

  • RAG-First：先检索背景知识，再推理，召回率决定上限。

  • Tool-Forward：工具定义先行，模型只负责调用决策。
