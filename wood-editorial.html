01 · FRAMEWORK

核心框架：四种主流 Agent 架构

目前主流的 LLM Agent 架构可以分为四类：ReAct、Plan-and-Execute、 React 混合 和 反思式 。每种架构对应不同的任务类型和延迟预算。

1

定义工具边界

明确每个工具的输入输出格式，避免模糊描述导致的幻觉调用。

2

设计错误回退

每个工具失败后应有明确的降级路径，而不是直接抛异常。

⚠ 注意

不要把 LLM 能力的边界当成工具设计的边界——工具应当超越模型能力本身。
