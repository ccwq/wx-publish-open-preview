第一步：安装 Codex CLI

1

通过 pip 安装

Codex CLI 支持 Python 3.9+，使用 pip 一键安装，安装完成后验证版本。

$ pip install codex-cli
2

验证安装

运行以下命令确认安装成功，应输出版本号。

$ codex --version
OUTPUT codex, version 1.4.2
Type "codex help" for usage information.

第二步：配置 API Key

3

设置环境变量

将 API Key 写入环境变量，Codex CLI 启动时自动读取。支持 .env 文件或 shell profile 两种方式。

$ export CODEX_API_KEY=sk-xxxxxxxxxxxxxxxx
CONFIG CODEX_API_KEY sk-xxxxxxxxxxxxxxxx — 从 dashboard.codex.dev 获取
CODE BLOCK # .env 文件示例
CODEX_API_KEY=sk-xxxxxxxxxxxxxxxx
CODEX_MODEL=gpt-4o
CODEX_MAX_TOKENS=4096
NOTE

API Key 请勿提交至代码仓库。推荐将 .env 加入 .gitignore，或使用 secret 管理工具注入环境变量。

第三步：初始化工作区

4

创建项目

在当前目录初始化 Codex 工作区，自动生成 .codex/ 配置目录与 cache 子目录。

$ codex init --project my-workspace
5

查看状态

初始化后可用 status 子命令查看当前工作区状态、配网状态与缓存情况。

$ codex status
OUTPUT Project: my-workspace
Model: gpt-4o (connected ✓)
Cache: 0 tasks, 0 MB
Ready to run.

进阶：自定义 Prompt 模板

Codex CLI 支持通过 ~/.codex/templates/ 目录加载自定义 Prompt 模板。创建同名 YAML 文件即可覆盖默认行为。

CODE BLOCK # ~/.codex/templates/review.yaml
name: Code Review
prompt: |
Review the following code for bugs,
security issues, and style problems.
model: gpt-4o

运行 codex run review ./src 即可触发自定义模板工作流。

NOTE

模板支持 Jinja2 语法，可在 prompt 中引用文件路径、变更列表等变量，实现条件化生成。
