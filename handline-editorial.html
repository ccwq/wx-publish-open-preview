手绘基因，收敛成一套整齐的设计系统

保留米纸底与发丝线锚点，把散落的虚线框、旋转便签和多色标签，收敛为单一主强调、统一容器与 8px 间距网格。少即是优雅。

1 套容器 / 2 处深色锚点 / 8px 间距网格

容器退后，内容向前：所有文字住进同一种暖白卡片，强调色只在关键处落笔。

— handline-editorial v4 设计哲学

01 / ONE CARD LANGUAGE

统一容器语言

全文只用一种卡片

纸白底 #FFFDF8，1px 浅棕细线 #EDE6D8，直角，内边距 12px。没有阴影、没有虚线、没有旋转——容器退后，内容向前。

提示条只换左色条

同样的白卡，加一条 3px 语义色边与 mono 大写标签行，就是提示、洞察与结论的家。

02 / BEFORE / AFTER

正反对比要成对

❌ V2 · 杂乱

虚线框、旋转便签、蓝橙红绿紫五种强调色同屏抢焦点。

✅ V3 · 整齐优雅

单一主强调，语义色只留给对错；对比卡上下全宽堆叠，390px 不挤。

03 / TOKENS AT A GLANCE

速查表是行式表格

深墨INK

#181614 · 仅用于 Hero 与 Footer 两处深色锚点

主强调ACCENT

#A76632 · 章节序号、提示条色条、正文关键词

卡片线BORDER

#EDE6D8 · 全文唯一边框色，弱化框架感

HOW TO USE

中文名固定 64px 列，英文组件名 16px 衬线加粗，别名独立成行——右列同行会在移动端换行不均（v3b 实证）。

04 / TWO-TONE BARS · 8PX GRID

条形图只分两阶

章节间距 24px

卡内边距 12px

卡片间距 8px

行内微距 4px

WHY IT MATTERS

条形头部 3 名用主强调，其余一律浅棕 #CBBFA8——禁多色梯队，数据自己会说话。

05 / SEARCH → MAP → PROMPT

3 步应用这套主题

01锁定设计 DNA

米纸底 + 浅底 Hero 与深墨 Footer 上下锚点呼应。

02只用统一容器

所有内容住进同一种白卡，提示条只加左色条。

03强调色点在关键处

章节序号、关键词、条形图头部——其他地方交给墨与纸。
