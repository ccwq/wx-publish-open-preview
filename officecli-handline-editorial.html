05 · CORE CAPABILITIES

🎨 HTML 渲染引擎

将 .docx / .xlsx / .pptx 高保真渲染为 HTML / PNG，无需依赖 COM 接口或 LibreOffice。

  • 原理：原生 OOXML 解析，保留字体/颜色/布局
  • 输出：HTML 矢量渲染 或 PNG 位图截图
  • 优势：Agent 看到渲染结果后才能精准修改
  • 限制：复杂 VBA 宏和 OLE 对象不渲染

📊 350+ Excel 函数解析

内置公式引擎，覆盖 SUM / VLOOKUP / INDEX / MATCH / XLOOKUP 等 350+ 函数，解析在本地完成。

  • 数学类：SUM, AVERAGE, COUNT, MAX, MIN, IF, IFS
  • 查找类：VLOOKUP, HLOOKUP, INDEX, MATCH, XLOOKUP
  • 文本类：CONCATENATE, LEFT, RIGHT, MID, TRIM
  • 输出：结构化 JSON，结果可被 Agent 直接使用

🔌 MCP Server 原生

内置 MCP Server，原生对接 Claude Code、Codex、Cursor、OpenClaw 等主流 AI Agent。

  • 接入方式：一行配置 settings.json
  • 协议：标准 MCP over stdio
  • 工具：doc/xlsx/ppt read/write/update/render
  • 适用：需要 Agent 操作 Office 文档的所有场景

📁 路径式元素访问

document.tables[0].rows[2].cells[1] 语法，比操作 XML 直观 10 倍。

  • 语法：类似 JavaScript 的点号访问
  • 模板：一份模板 + JSON = N 份定制化文档
  • 批量：高效复用上下文，适合大规模文档生产
  • 示例：paragraphs[0].bold = true; cells[2][1].value = "新内容"

🤖 AGENT NOTE

为什么 AI Agent 应该用 OfficeCLI 而不是自己写 Python 脚本？

传统方式让 AI 写 Python 代码调用 python-docx / openpyxl，改个颜色得重跑一遍。OfficeCLI 让 AI 直接操控文档，看见结果再迭代——所见即所得的 Agent 版本。

07 · COMPARISON
对比项 python-docx + openpyxl OfficeCLI
Agent 集成 需写 Python 脚本，3 套格式库 一行命令，3 种格式统一接口
MCP 支持 无，需自行封装 原生 MCP Server，开箱即用

跨平台 ✅ Linux / macOS / Windows ✅ Linux / macOS / Windows WSL
