说明书风工具观察：把一台虚构工具拆成五章

━━━

主编辑风完整演示：编号章节、统计行、Pill、模块矩阵、记录卡与流程结论；全部数值为演示口径。

这是一份「主编辑风」主题的完整演示样稿，用于逐个展示组件语义：红黑编号章节条、纵向统计行、状态 Pill、模块矩阵、记录卡与流程结论块。文中出现的工具、数值与结论全部是演示口径，不指向任何真实项目。

01 TOOL OVERVIEW

工具速览

主编辑风把一次工具观察压成一本「说明书」：黑框章节、红色编号、暖白纸底。演示对象是虚构命令行工具 shelfkit，它的定位是「把散落的本地文档收拢成可检索书架」。演示口径下，它有四个核心数字：

12k演示星标
340演示插件
100%离线可用
9演示语言

状态信号用彩色 Pill 表达，红黑白之外只允许蓝黄绿三种辅助色，其余装饰一律不上：

高密度模块化实验特性已验证

Pill 行之后补一句正文，说明颜色语义：蓝色是信息，黄色是等待，绿色是确认，红色是警示。这套语义在全文保持一致，读者不需要重新学习。

特征 · FEATURE

所有容器都是纵向单列自然流，窄屏按百分比收缩，不依赖固定像素宽度。

02 SETUP

安装与上手

安装只有一行命令（演示口径）：

$ bash

npm install -g shelfkit

shelfkit init ~/docs

上手路径被压成四步，每步一行，编号用红色两位数字：

01 扫描指定目录，建立文档索引

02 生成默认书架视图与检索入口

03 挂接插件，扩展格式支持

04 导出只读书架，交给读者

03 MODULE MATRIX

模块矩阵

模块矩阵是本主题的骨干组件：一行一个模块，名称加状态 Pill，行间用浅棕细线分隔。演示口径下，三个模块的状态分布如下：

核心索引stable

格式插件beta

云同步wip

阅读规则

▪ 「稳定」模块可直接进入生产流程

▪ 「测试」模块需双人在场执行

▪ 「进行中」模块只出现在路线图

04 SPEC SHEET

参数规格

参数规格用记录卡表达：每行一张卡，卡首是参数名，字段按「表头： 值」对齐，左缘四像素红色竖线是每张卡的视觉签名。

索引延迟

说明： 千篇文档以内的演示取值

离线能力

数值： 完整

说明： 断网时检索与导出不受影响

插件协议

数值： v2

说明： 向后兼容 v1 的只读插件

05 RISKS

风险与备注

警示 · WARNING

本样稿的全部数值与结论都是演示口径，仅用于验证版式，不构成对任何真实工具的评价。

备注 · NOTE

记录卡的「表头： 值」格式是逐字符合同，改动冒号或空格会导致校验失败。

备注 · NOTE

章节编号由渲染器统一累计，流程结论之后不再出现编号章节。

流程结论 · CONCLUSION

流程结论

把五章连起来，主编辑风的阅读动线是一条单向流程：速览给全景，安装给路径，矩阵给边界，规格给证据，风险给护栏。结论块用绿底表达「确认」，是全文唯一的大面积绿色容器。
